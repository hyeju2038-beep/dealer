# 조선 블랙잭 보드게임 룰 요약

## 1. 게임 목표

딜러인 `물주`보다 카드 합이 `21`에 더 가까우면 승리합니다.

단, 카드 합이 `21`을 넘으면 `버스트`가 되어 패배합니다.

## 2. 카드 점수

| 카드 | 점수 |
| --- | --- |
| 2~10 | 숫자 그대로 |
| J, Q, K | 10 |
| A | 1 또는 11 |

### A 카드 규칙

`A`는 상황에 따라 `1` 또는 `11`로 계산합니다.

- `11`로 계산해도 `21`을 넘지 않으면 `11`로 계산합니다.
- `11`로 계산하면 `21`을 넘는 경우 `1`로 계산합니다.
- 여러 장의 `A`가 있을 경우, 가장 유리한 점수로 자동 계산합니다.

예시:

| 카드 조합 | 계산 |
| --- | --- |
| A + 8 | 19 |
| A + K | 21 |
| A + 9 + 5 | 15 |
| A + A + 8 | 20 |

## 3. 게임 구성

플레이어는 딜러와 대결합니다.

게임에는 다음 참가자가 있습니다.

| 참가자 | 설명 |
| --- | --- |
| 플레이어 | 사용자가 직접 조작하는 참가자 |
| 물주 | 딜러 역할 |
| 객인 가(A) | 자동으로 진행되는 봇 참가자 |
| 객인 나(B) | 자동으로 진행되는 봇 참가자 |

플레이어와 봇들은 각각 엽전을 걸고 게임에 참여합니다.

## 4. 초기 세팅

1. 플레이어는 기본 엽전 `500냥`을 가지고 시작합니다.
2. 봇 참가자는 각각 `300냥`을 가지고 시작합니다.
3. 플레이어가 원하는 만큼 엽전을 베팅합니다.
4. `패 돌리기`를 누르면 게임이 시작됩니다.
5. 플레이어, 딜러, 봇 참가자는 각각 카드 2장을 받습니다.

## 5. 베팅

플레이어는 패를 받기 전에 엽전을 걸어야 합니다.

선택 가능한 베팅 단위는 다음과 같습니다.

| 엽전 | 금액 |
| --- | --- |
| 五 | 5냥 |
| 十 | 10냥 |
| 廿五 | 25냥 |
| 五十 | 50냥 |
| 百 | 100냥 |

`무르기`를 누르면 현재 선택한 판돈을 취소할 수 있습니다.

## 6. 카드 진행

플레이어는 자신의 차례에 다음 행동을 선택합니다.

| 행동 | 설명 |
| --- | --- |
| Hit / 받기 | 카드 1장을 더 받습니다. |
| Stand / 멈춤 | 더 이상 카드를 받지 않고 승부를 기다립니다. |
| Double / 따블 | 현재 베팅만큼 추가로 걸고 카드 1장을 받은 뒤 자동으로 멈춥니다. |

## 7. 딜러 규칙

딜러인 물주는 정해진 규칙에 따라 행동합니다.

- 딜러의 점수가 `16` 이하이면 카드를 더 받습니다.
- 딜러의 점수가 `17` 이상이면 멈춥니다.
- 딜러가 `21`을 넘으면 버스트입니다.

## 8. 봇 참가자 규칙

객인 가(A), 객인 나(B)는 자동으로 게임에 참여합니다.

- 각 봇은 무작위로 판돈을 겁니다.
- 봇은 자신의 카드 합에 따라 자동으로 Hit 또는 Stand를 선택합니다.
- 봇도 `21`을 넘으면 버스트가 됩니다.
- 봇의 승패도 딜러와 비교해 정산됩니다.

## 9. 승패 결정

플레이어와 딜러의 카드 합을 비교합니다.

| 상황 | 결과 |
| --- | --- |
| 플레이어가 21 초과 | 버스트, 패배 |
| 딜러가 21 초과 | 플레이어 승리 |
| 플레이어 점수 > 딜러 점수 | 플레이어 승리 |
| 딜러 점수 > 플레이어 점수 | 플레이어 패배 |
| 점수가 같음 | 무승부 |
| 처음 받은 2장으로 21 | 블랙잭 |

## 10. 정산

| 결과 | 정산 |
| --- | --- |
| 승리 | 베팅한 금액만큼 추가 획득 |
| 패배 | 베팅한 금액 손실 |
| 무승부 | 베팅한 금액 반환 |
| 블랙잭 승리 | 판돈의 1.5배 보상 |

예시:

| 베팅 | 결과 | 정산 |
| --- | --- | --- |
| 10냥 | 승리 | 20냥 반환 |
| 10냥 | 패배 | 10냥 손실 |
| 10냥 | 무승부 | 10냥 반환 |
| 10냥 | 블랙잭 | 25냥 반환 |

## 11. 기록 시스템

게임이 끝나면 이번 판을 장부에 기록할 수 있습니다.

기록에는 다음 내용이 저장됩니다.

- 게임 시간
- 승리 / 패배 / 무승부
- 플레이어 카드
- 딜러 카드
- 베팅 금액
- 엽전 변화량
- 남은 엽전

지난 기록 화면에서 전체 전적과 누적 손익을 확인할 수 있습니다.

## 핵심 한 줄

**조선 블랙잭은 엽전을 걸고 딜러보다 21에 가까운 점수를 만드는 조선풍 블랙잭 게임입니다.**
